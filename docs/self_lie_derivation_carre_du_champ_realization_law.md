# Self-Lie derivation / carre-du-champ realization law

## Purpose

The abstract shell-ladder stop theorem proves that skewness, Casimir nullity, the
Hodge square, energy-ray geometry, heat sorting, projective flatness and positive
critical-spread transport are not sufficient as an abstract package for no-escape.
The missing ingredient must distinguish the literal Navier--Stokes conservative
operator

\[
\mathbb J_{NS}(u)v
=P_\sigma(v\times Cu)
=C^{-1}[Cu,v]_{\rm Lie}
\]

from an arbitrary skew map which merely annihilates `Cu`.

This note isolates the shortest such whole-operator compatibility currently visible.
The divergence-free Lie bracket is a fixed first-order derivation, while viscosity is
the square of the fixed first-order Hodge operator.  Their failure to commute is not
arbitrary:

\[
\boxed{
A[f,g]_{\rm Lie}
-[Af,g]_{\rm Lie}
-[f,Ag]_{\rm Lie}
=-2\sum_{j=1}^3
[\partial_jf,\partial_jg]_{\rm Lie},
\qquad
A=-\Delta=C^2.
}
\]

Equivalently,

\[
\boxed{
[A,\operatorname{ad}_f]
=\operatorname{ad}_{Af}
-2\sum_j
\operatorname{ad}_{\partial_jf}\,\partial_j.
}
\]

This is the Lie-bracket analogue of the heat carré-du-champ identity.  It is a fixed
realization law: an arbitrary shell-dependent rank-two skew operator does not satisfy
it.

For the actual heat-renormalization defect

\[
\mathfrak N_h
=S_hX_E(u)-X_E(S_hu),
\qquad
S_h=e^{-hA/2},
\]

curl converts the already-known cross-product defect into exactly this Lie defect:

\[
\boxed{
C\mathfrak N_h
=S_h[Cu,u]_{\rm Lie}
-[S_hCu,S_hu]_{\rm Lie}.
}
\]

Hence

\[
\boxed{
C\mathfrak N_h
=2\int_0^{h/2}
P_{h/2-r}
\sum_j
[\partial_jP_rCu,\partial_jP_ru]_{\rm Lie}
\,dr,
}
\]

where `P_s=e^{-sA}`.

The Fourier triangle law is a coordinate shadow of the same identity.  For
`k=p+q`, divergence-free polarizations force the bracket symbol to carry the
transverse triangle-area factor `|p cross q|`; the heat renormalization of the same
pair is controlled by the longitudinal factor `p dot q`.  The two obey

\[
\boxed{
(p\cdot q)^2+|p\times q|^2=|p|^2|q|^2.
}
\]

Thus spatial transfer and heat renormalization are not separately tunable channels:
they are complementary faces of one fixed pair geometry.

This still does not prove no-escape.  An exact sparse opposite-helicity shell datum
with orthogonal wavevectors has **positive** second critical-center acceleration, so
there is no universal one-shell second-order barrier.  The remaining theorem must be
cumulative: it must prevent an infinite sequence of phase-coherent/intermittent Lie
interactions from sustaining the boundary action Zeno.

## 2. The Hodge square has one exact Lie-derivation defect

Let

\[
A=-\Delta.
\]

Because the Lie bracket is bilinear with constant-coefficient first derivatives,
ordinary differentiation gives

\[
\Delta[f,g]
=[\Delta f,g]+[f,\Delta g]
+2\sum_j[\partial_jf,\partial_jg].
\]

Multiplying by `-1` yields

\[
\boxed{
A[f,g]
=[Af,g]+[f,Ag]
-2\sum_j[\partial_jf,\partial_jg].
}
\]

Thus

\[
\boxed{
A[f,g]-[Af,g]-[f,Ag]
=-2\sum_j[\partial_jf,\partial_jg].
}
\]

In operator notation,

\[
\boxed{
[A,\operatorname{ad}_f]
=\operatorname{ad}_{Af}
-2\sum_j
\operatorname{ad}_{\partial_jf}\,\partial_j.
}
\]

This is a second-order product defect generated by the same first spatial
derivatives which define the literal local Lie algebra.

It is stronger typing than saying only that `A` is the viscous square and
`ad_f` is a transport operator: their commutator has a forced local Gram/bilinear
source.

**Classification: Exact Lie carré-du-champ identity.**

## 5. Fourier symbol: triangle area is forced by incompressible Lie geometry

Write Fourier modes of divergence-free fields as

\[
f_p\perp p,
\qquad
g_q\perp q.
\]

For

\[
k=p+q,
\]

the ordered Fourier contribution to the Lie bracket is

\[
\boxed{
\mathcal B_{k;p,q}(f_p,g_q)
=i\left[
(f_p\cdot q)g_q
-(g_q\cdot p)f_p
\right].
}
\]

Because `f_p` is orthogonal to `p`,

\[
|f_p\cdot q|
\le
\frac{|p\times q|}{|p|}|f_p|.
\]

Likewise,

\[
|g_q\cdot p|
\le
\frac{|p\times q|}{|q|}|g_q|.
\]

Therefore

\[
\boxed{
|\mathcal B_{k;p,q}|
\le
|p\times q|
\left(
\frac1{|p|}+\frac1{|q|}
\right)
|f_p||g_q|.
}
\]

The bracket vanishes for a degenerate collinear Fourier triangle before any norm
estimate is used.

For the NS choice `f=Cu`, `g=u`, an ordered term obeys

\[
\boxed{
|\mathcal B_{k;p,q}(Cu_p,u_q)|
\le
|p\times q|
\left(1+\frac{|p|}{|q|}\right)
|u_p||u_q|.
}
\]

After inverse curl, the corresponding ordered Euler-velocity contribution has the
soft-triangle factor

\[
\boxed{
\frac{|p\times q|}{|k|}.
}
\]

This is stronger than bare triangle support/no-teleportation.

**Classification: Exact Fourier symbol / rigorous area-factor bound.**

## 6. Heron gives a quantitative upper-edge null law

Let

\[
a=|p|,
\qquad
b=|q|,
\qquad
c=|p+q|.
\]

The triangle area is

\[
\Delta=\frac12|p\times q|.
\]

Heron's identity gives

\[
\boxed{
4|p\times q|^2
=(a+b+c)(-a+b+c)(a-b+c)(a+b-c).
}
\]

Since

\[
a+b+c\le2(a+b),
\]

\[
-a+b+c\le2b,
\qquad
 a-b+c\le2a,
\]

one obtains

\[
\boxed{
|p\times q|^2
\le
2ab(a+b)(a+b-c).

\]

Thus transfer toward the maximal output edge `c=a+b` is softened by the square root
of the triangle slack.

For equal input shells

\[

\[
\boxed{
\left(
\frac{|p\times q|}{|p+q|}
\right)^2
=L^2-\frac{|p+q|^2}{4}.
}
\]

Hence exact doubling `|p+q|=2L` carries zero projected Lie/Lamb coupling.

This does not forbid a cascade through nondegenerate interior triangles.

**Classification: Exact Heron identity / rigorous soft-edge consequence.**
