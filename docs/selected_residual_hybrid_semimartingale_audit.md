# Selected residual hybrid semimartingale audit

The persistent same-replica library evolves continuously under one common Brownian
flow, while the hysteretic first-bad selector is piecewise constant and changes only
at finite entry/resolve events.  The active selected residual is therefore a hybrid
càdlàg process with two physically different sources of path variation:

1. continuous Brownian evolution of the underlying physical library;
2. finite observer/readout jumps when the active germ changes.

These two mechanisms must not be merged into one “q.v. bank”.  The continuous
Brownian bracket is a stochastic producer.  A finite selector jump contributes a
jump square to the **optional quadratic variation of the observed càdlàg path**, but
that jump square is reset/path variation and can accumulate on a closed selector
excursion with zero net physical state change.

---

## 1. Frozen-selector intervals inherit the active library martingale

Let the persistent same-replica library satisfy

\[
d\boldsymbol\chi
=\sqrt{2\nu}\,\mathcal Q\,dW,
\]

and let `E_g` be the active germ extraction on an interval where the hysteretic
selector is frozen.  The selected residual is

\[
Y=E_g\boldsymbol\chi.
\]

Therefore

\[
\boxed{
dY
=\sqrt{2\nu}\,E_g\mathcal Q\,dW.
}
\]

Its continuous Brownian q.v. source is

\[
\boxed{
\frac{d[Y]^c}{d\sigma}
=2\nu(E_g\mathcal Q)(E_g\mathcal Q)^T
=E_g\Gamma_{\rm lib}E_g^T.
}
\]

No selector derivative appears on a frozen branch.

**Status: Exact identity.**

---

## 2. A pure selector event is a finite readout jump

Assume the physical library itself is continuous at a selector-only event and the
active readout changes from `E_-` to `E_+`.  Then

\[
\boxed{
\Delta Y
=(E_+-E_-)\boldsymbol\chi.
}
\]

This jump is finite variation/readout revaluation.  It is not a Brownian increment
and introduces no atom into the **continuous** bracket `[Y]^c`.

**Status: Exact pathwise identity / physical typing.**

---

## 3. Optional quadratic variation contains the jump square

For a càdlàg semimartingale, total optional quadratic variation contains both its
continuous bracket and the squared jumps.  Therefore along a selected path,

\[
\boxed{
[Y]_T
=[Y]^c_T
+\sum_{\tau\le T}
\Delta Y_\tau\Delta Y_\tau^T.
}
\]

At one selector switch,

\[
\boxed{
\Delta[Y]_\tau
=\Delta Y_\tau\Delta Y_\tau^T.
}
\]

This statement does **not** contradict the earlier result that a finite-variation
selector creates no stochastic carré-du-champ/Brownian source.  The objects are
different:

- continuous stochastic q.v. producer: `d[Y]^c`;
- càdlàg path jump square: `Delta Y Delta Y^T`.

**Status: Exact semimartingale identity / theorem-type clarification.**

---

## 4. The jump dyad reproduces the exact reset faces

Write

\[
Y_+=Y_-+\Delta Y.
\]

Then

\[
\boxed{
Y_+Y_+^T-Y_-Y_-^T
=\Delta Y\,Y_-^T
+Y_-\Delta Y^T
+\Delta Y\Delta Y^T.
}
\]

The three terms are exactly the left, right, and quadratic reset faces already seen
in the selector pair ledger.

The quadratic face is positive semidefinite, but the two linear faces are signed.
Consequently the endpoint dyad revaluation is not determined by the jump square
alone.

**Status: Exact finite-jump identity.**

---

## 5. Hybrid optional q.v. is a sum of physically distinct pieces

For any interval partitioned by finitely many selector events,

\[
\boxed{
[Y]
=\int E_{g(\sigma)}\Gamma_{\rm lib}(\sigma)E_{g(\sigma)}^T\,d\sigma
+\sum_{\tau}
\Delta Y_\tau\Delta Y_\tau^T.
}
\]

This is an exact pathwise decomposition once the piecewise-constant selector path
and same-replica library path are supplied.

It is useful precisely because the two terms are **not** given the same physical
meaning.  The integral is continuous Brownian variation generated by Navier--Stokes
viscosity through the stochastic flow.  The sum is observer/reset variation caused
by changing the selected readout.

**Status: Exact conditional hybrid semimartingale law.**

## 6. Closed selector excursion: positive jump q.v., zero net state change

Freeze a two-germ library state and let the selector follow

\[
0\longrightarrow1\longrightarrow0.
\]

The jump vectors are opposite:

\[
\Delta Y_{10}=-\Delta Y_{01},
\]

so

\[
\boxed{
Y_{\rm final}-Y_{\rm initial}=0.
}
\]

But the jump contribution to optional q.v. is

\[
\boxed{
\Delta Y_{01}\Delta Y_{01}^T
+\Delta Y_{10}\Delta Y_{10}^T
=2\Delta Y_{01}\Delta Y_{01}^T,
}
\]

which is positive whenever the two readouts differ.

Therefore cumulative selector jump-square is path length, not a state function and
not a monotone physical uncertainty/covariance bank.

**Status: Exact calibration / rigorous no-bank consequence.**

## 7. Exact one-mode Navier--Stokes selector excursion

Use the exact half-period one-mode residual packets from the selected-lineage audit:

\[
\chi_1=-\chi_0\ne0.
\]

For the selector excursion `0->1->0`,

\[
\Delta Y_{01}=-2\chi_0e_z,
\qquad
\Delta Y_{10}=+2\chi_0e_z.
\]

Hence

\[
\boxed{
Y_{\rm final}=Y_{\rm initial},
}
\]

while

\[
\boxed{
\sum_{\tau}
\operatorname{tr}(\Delta Y_\tau\Delta Y_\tau^T)
=8\chi_0^2>0.
}
\]

The exact smooth Navier--Stokes calibration therefore activates the distinction:
selector jump-square can be strictly positive on a closed readout excursion that
returns to exactly the same selected physical residual.

**Status: Audited calibration using an exact Navier--Stokes solution.**

## 8. Why selector jump q.v. is not a replacement for reset covariance algebra

The optional jump square

\[
\Delta Y\Delta Y^T
\]

is only the quadratic reset face.  The endpoint second-moment/dyad jump also contains

\[
\Delta Y\,Y_-^T+Y_-\Delta Y^T.
\]

At the ensemble level, centering introduces the corresponding mean revaluation as
well.  Thus one cannot replace the full selector reset ledger by “add the jump q.v.”
without losing signed pair content.

**Status: Rigorous consequence of the exact jump dyad identity.**

## 9. Physical packet events remain a separate jump type

This note treats a **selector-only** jump where the persistent physical library is
continuous.  If an actual current refinement/reselection occurs at the same physical
time, the library itself has a finite map and the post-selected value is instead

\[
E_+A_{\rm full}\boldsymbol\chi_-.
\]

The physical event map and selector reset must then be composed using the event
normal form and selector-readout factorization already audited.  Their order or
combined map is physical event data and is not invented here.

**Status: Exact scope boundary.**

## 10. Refined first-bad hybrid frontier

For a supplied same-replica library and supplied piecewise-constant selector path,
the selected process now has a complete same-clock hybrid path law:

\[
\boxed{
\begin{cases}
dY=\sqrt{2\nu}\,E_g\mathcal Q\,dW,
&\text{between selector events},\\[1mm]
\Delta Y=(E_+-E_-)\boldsymbol\chi,
&\text{at selector-only events}.
\end{cases}}
\]

The remaining first-bad questions are no longer semimartingale bookkeeping:

- which NS badness/resolve predicates produce the event times;
- which candidate library and replica/clock are physical;
- whether physical packet refinement occurs simultaneously with a selector switch;
- support locality and full pair/projector control;
- moving-cut and cross-clock ancestry/future-bank identification.

**Status: hybrid selected-path law audited-conditional on a specified library and selector path; actual first-bad timing/event instantiation remains Open-literal/Open.  No restart/continuation/regularity theorem claimed.**
