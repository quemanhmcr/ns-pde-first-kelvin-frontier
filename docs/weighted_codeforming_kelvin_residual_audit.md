# Physical frame-weighted codeforming Kelvin residual audit

## Scope

This note corrects the *topology* suggested by the reverse-age codeforming
martingale core.  It does not add a norm estimate.  It asks what physical object
Navier--Stokes itself reconstructs from the codeforming residual.

On a smooth material segment let

\[
\dot L=-A(X)L,
\qquad
r=L\chi,
\qquad
M_L=L^TL.
\]

Here `chi` is the reverse codeforming finite-shape residual and `r` is the actual
physical reconstructed Kelvin residual already audited from orientation data.
The distinction between these two vectors is essential.

No future-bank, ancestry, first-bad, restart, continuation, or regularity

## 1. The physical residual topology is the primal line metric

Pathwise,

\[
\boxed{|r|^2=\chi^TM_L\chi.}
\]

Thus the physical topology seen by the reconstructed residual is not the raw
Euclidean size of `chi`.  It is `chi` measured by the actual primal material-line
metric `M_L=L^T L`.

For a fixed frame, or conditionally on geometry so that `L` is fixed, write

\[
m_\chi=\mathbb E\chi,
\qquad
C_\chi=\operatorname{Cov}(\chi),
\qquad
Q_\chi=C_\chi+m_\chi m_\chi^T.
\]

Then

\[
\boxed{
\mathbb E|r|^2
=
\operatorname{tr}(Q_\chi M_L)
=
m_\chi^TM_Lm_\chi
+
\operatorname{tr}(C_\chi M_L).
}
\]

The two terms are physically different:

- `m_chi^T M_L m_chi`: deterministic finite-shape **bias** carried into physical
  space by the line frame;
- `tr(C_chi M_L)`: stochastic **spread** carried into physical space by the same
  frame.

This is a **fixed-frame / conditional-on-geometry identity**.  It is not yet a
factorization of the full stochastic current-shape ensemble.

**Status: Exact identity / physical topology correction.**

If

\[

\[
\boxed{

\[
\boxed{

2\nu\operatorname{tr}
(\widetilde Q\widetilde Q^TM_L).
}
\]

Again, raw codeforming q.v. is not the physical q.v. topology unless the line
frame is fixed and uniformly comparable to the identity.

**Status: Exact Itô identity.**

## 3. Random frame: a mandatory metric--residual correlation face

The first-bad/full-state ensemble is more subtle because `L` itself is a random
finite-variation state coordinate generated by the noisy anchor history.  The
literal quantity is

\[
\boxed{
\mathcal E_{\rm phys}
=\mathbb E[\chi^TM_L\chi]
=\mathbb E\,\operatorname{tr}(M_L\,\chi\chi^T).
}
\]

Let

\[
\bar M=\mathbb E M_L,
\qquad
\bar Q=\mathbb E(\chi\chi^T).
\]

Then

\[
\boxed{
\mathcal E_{\rm phys}
=
\operatorname{tr}(\bar M\bar Q)
+
\mathbb E\operatorname{tr}
[(M_L-\bar M)(\chi\chi^T-\bar Q)].
}
\]

The second term is the **random-frame mixed metric--residual correlation**.  It is
signed and cannot be discarded.

For two equal-weight replicas this becomes the exact pair identity

\[
\boxed{
\frac12\operatorname{tr}(M_1Q_1+M_2Q_2)
=
\operatorname{tr}(\bar M\bar Q)
+
\frac14\operatorname{tr}[(M_1-M_2)(Q_1-Q_2)].
}
\]

A simple exact algebraic referee gives mixed face `+3/4`; exchanging which replica
carries the residual gives `-3/4`.  Therefore the full-state physical residual
energy is not closed by mean metric times mean residual second moment.

**Status: Exact two-replica identity / rigorous cross-face necessity.**

## 4. Exact quadratic Navier--Stokes: raw mean bias need not collapse

Use the exact smooth shear

\[
u=(U(y,t),0,0),
\qquad
U=y^2+2\nu t,
\]

for which `U_t-nu U_yy=0` and the advective term vanishes.

Take the translated `xy` square

\[
0\le x\le\rho,
\qquad
0\le y_{\rm rel}\le\rho,
\]

with normal `+e_z` and isotropic frame `L=rho I`.  Since
`omega_z=-U_y`, exact Stokes gives the local-frame error

\[
\boxed{\varepsilon_z=-\rho^3.}
\]

Because `J=det L=rho^3`,

\[
\boxed{\chi_z=\varepsilon_z/J=-1.}
\]

The raw codeforming bias therefore does **not** tend to zero.  But the physical
residual is

\[
\boxed{r_z=(L\chi)_z=-\rho\to0,}
\]

and its physical weighted bias energy is

\[
\boxed{m_\chi^TM_Lm_\chi=\rho^2\to0.}
\]

Therefore **raw chi bias collapse is not necessary** for physical Kelvin descent.
The earlier raw-bias first-bad target was too strong.

**Status: Audited calibration (exact Navier--Stokes) / rigorous target correction.**

## 5. Exact one-mode Navier--Stokes: raw stochastic spread need not collapse

Take

\[
U(Y,t)=e^{-\nu k^2t}\cos(kY).
\]

For the same asymmetric square, exact Stokes and local subtraction give

\[
\boxed{
\chi_\rho(Y)
=-\frac{U(Y+\rho)-U(Y)-\rho U_y(Y)}{\rho^2}.
}
\]

Therefore

\[
\boxed{
\chi_\rho\longrightarrow-\frac12U_{yy}(Y).
}
\]

The only Brownian coordinate is the anchor `Y`, so the codeforming residual noise
is

\[
q_{\chi,\rho}=\partial_Y\chi_\rho,
\]

with exact smooth limit

\[
\boxed{
q_{\chi,\rho}\longrightarrow-\frac12U_{yyy}(Y),
}
\]

generically nonzero.  Raw codeforming q.v. can therefore stay order one.

But the physical residual/noise contains the line-frame factor:

\[
r_\rho=\rho\chi_\rho,
\qquad
q_{r,\rho}=\rho q_{\chi,\rho},
\]

so

\[
\boxed{r_\rho\to0,\qquad q_{r,\rho}\to0.}
\]

Thus **raw chi spread collapse is not necessary** either.

**Status: Audited calibration (exact periodic Navier--Stokes) / rigorous spread-target correction.**
