# Same-replica residual-library dynamics audit

The selected-readout audit showed that arbitrary hysteretic selector switches require
a persistent candidate library rather than only the currently selected packet.  The
next physical question is whether Navier--Stokes/Kelvin dynamics provides an exact
law for such a library.

For a finite library of physical closed packets carried by **one stochastic-flow
replica**, the answer is yes.  Every packet is driven by the same three-dimensional
spatial Wiener motion.  The individual codeforming finite-residual martingales
therefore stack into one tall common-noise martingale.  The full germ-pair
quadratic-variation matrix is a single Gram tensor, not a block-diagonal collection
of independent per-germ noises.

The scope matters: this is a theorem for a specified finite same-replica physical
packet library.  The repository still has not declared that its programme-specific
first-bad candidate library is exactly such a library.

---

## 1. One stochastic-flow replica means one common spatial Wiener motion

The exact stochastic Kelvin flow uses

\[
dX=-u(X,r)\,d\sigma+\sqrt{2\nu}\,dW,
\]

where the same spatial Brownian vector `W in R^3` drives the whole stochastic flow
replica.  Distinct material currents inside that replica are not assigned
independent Brownian motions.

For a finite packet library `g=1,...,N`, let the exact reverse-age codeforming
residual law of packet `g` be

\[
\boxed{
d\chi_g=\sqrt{2\nu}\,Q_g\,dW,
}
\]

where `Q_g` is the packet's `3x3` residual anchor-noise response.

Each packet may have a different anchor, line frame, shape, and therefore a
different `Q_g`; the common object is the driving `dW` of the one replica.

**Status: Exact same-replica specialization of the already-audited codeforming
residual martingale law.**

## 2. Stack the library before taking any covariance

Define

\[
\boldsymbol\chi=
\begin{pmatrix}
\chi_1\\ \vdots\\ \chi_N
\end{pmatrix},
\qquad
\mathcal Q=
\begin{pmatrix}
Q_1\\ \vdots\\ Q_N
\end{pmatrix}
\in\mathbb R^{3N\times3}.
\]

Then the whole persistent library obeys

\[
\boxed{
d\boldsymbol\chi
=\sqrt{2\nu}\,\mathcal Q\,dW.
}
\]

There is no affine drift in these codeforming coordinates on a smooth material
segment.

**Status: Exact identity.**

---

## 3. The full library q.v. is one Gram tensor

The pathwise quadratic-variation source is

\[
\boxed{
\Gamma_{\rm lib}
=2\nu\,\mathcal Q\mathcal Q^T.
}
\]

Its ordered germ block is

\[
\boxed{
(\Gamma_{\rm lib})_{gh}
=2\nu\,Q_gQ_h^T.
}
\]

Thus the off-diagonal germ blocks are not optional connected-covariance
bookkeeping.  They are direct same-replica q.v. generated by the common physical
Brownian translation.

The instantaneous source also has a severe geometric rank constraint:

\[
\boxed{
\operatorname{rank}\Gamma_{\rm lib}
\le \operatorname{rank}\mathcal Q
\le 3.
}
\]

A large finite germ library can therefore have a high-dimensional residual state
but only a three-direction instantaneous stochastic forcing subspace in one replica.

**Status: Exact Gram identity / rigorous rank consequence.**

---

## 4. Selector readout is a congruence of the full library q.v.

For the germ extraction `E_g`,

\[
\boxed{
E_g\Gamma_{\rm lib}E_g^T
=2\nu Q_gQ_g^T.
}
\]

So the active selector simply reads one diagonal block of the persistent library
q.v. on a frozen branch.  A finite selector switch does not generate a new Brownian
source; it changes which block of the already-existing same-replica Gram is read.

This is consistent with the earlier finite reset/revaluation law: selector motion is
finite variation/readout logic, while q.v. is generated continuously by the common
Wiener motion.

**Status: Exact identity / physical typing.**

## 5. Any specified linear physical event pushes the Gram functorially

Let a finite physical event act on the library residual by

\[
\chi_+=A\boldsymbol\chi.
\]

Then its noise coefficient is

\[
\mathcal Q_+=A\mathcal Q,
\]

and therefore

\[
\boxed{
\Gamma_+
=A\Gamma_{\rm lib}A^T
=2\nu(A\mathcal Q)(A\mathcal Q)^T.
}
\]

Thus the stochastic source follows the same event normal form as the residual
second moment.  No new event-covariance term is required once the actual physical
map `A` is specified.

**Status: Exact event-functor identity.**

---

## 6. Mean bias and full centered spread remain separate at library level

Under square-integrability, the driftless stacked martingale gives

\[
\boxed{
\frac{d}{d\sigma}\mathbb E\boldsymbol\chi=0.
}
\]

For deterministic/fixed noise blocks,

\[
\boxed{
\frac{d}{d\sigma}\operatorname{Cov}(\boldsymbol\chi)
=2\nu\mathcal Q\mathcal Q^T.
}
\]

For state-dependent adapted coefficients, the corresponding expectation of the
pathwise q.v. source enters the covariance law.  The exact point is unchanged:
mean finite-shape bias and stochastic library spread are distinct physical faces,
and the spread includes all signed cross-germ blocks.

**Status: Exact martingale consequence under the stated integrability/fixed-noise
scope.**

## 7. Independent per-germ noise is a different physical model

If one incorrectly gives every packet its own independent Brownian driver, the
instantaneous q.v. would instead be block diagonal:

\[
\Gamma_{\rm ind}
=\operatorname{diag}
(2\nu Q_1Q_1^T,\ldots,2\nu Q_NQ_N^T).
\]

That model deletes every same-replica cross-germ block

\[
2\nu Q_gQ_h^T,
\qquad g\ne h.
\]

It is not equivalent to the common-flow replica.

**Status: Exact model distinction.**

## 8. Exact one-mode Navier--Stokes referee: cross-germ q.v. cancels the diagonals

Use the exact periodic one-mode shear

\[
u(y,t)=e^{-\nu k^2t}\cos(ky)e_x
\]

and two equal asymmetric packets of side

\[
\rho=\frac{\pi}{2k}
\]

with anchors

\[
Y_1=\frac{\pi}{2k},
\qquad
Y_2=\frac{3\pi}{2k}.
\]

The exact codeforming residual anchor-noise coefficients satisfy

\[
\boxed{
q_2=-q_1\ne0.
}
\]

Only the `z` residual / `y` Brownian entry is active in this calibration.  Therefore

\[
\boxed{
\Gamma_{12}=-\Gamma_{11},
\qquad
\Gamma_{22}=\Gamma_{11}>0.
}
\]

For the physical synthesis `(I,I)`, the same-replica residual noise cancels
pathwise:

\[
\boxed{
A\Gamma_{\rm lib}A^T=0.
}
\]

The counterfactual independent-noise model gives a strictly positive synthesized
q.v. instead.

Thus the cross-germ block is not merely allowed to be signed: exact smooth
Navier--Stokes activates the negative sign required for complete cancellation.

**Status: Audited calibration using an exact Navier--Stokes solution / rigorous
same-replica cross-block necessity.**

## 9. Structural persistent-library dynamics is now closed conditionally

The previous frontier phrase “persistent candidate-library dynamics” contained two
different questions.

If one is given a finite library of physical material packets in one stochastic-flow
replica, their codeforming residual dynamics and full q.v. state are now exact:

\[
\boxed{
d\boldsymbol\chi=\sqrt{2\nu}\mathcal QdW,
\qquad
\Gamma_{\rm lib}=2\nu\mathcal Q\mathcal Q^T.
}
\]

Selector readout and specified finite physical events act by the exact congruences
already derived.

What is not yet supplied by the first-bad programme is the actual candidate packet
library itself: which physical germs are retained, how their anchors/shapes/frames
are instantiated, and whether they are indeed carried in one common stochastic
replica compatible with the intended first-bad semantics.

**Status: Rigorous conditional same-replica library theorem; actual first-bad candidate-library instantiation remains Open-literal.**
